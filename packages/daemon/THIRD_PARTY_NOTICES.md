# Optional connection component

The one-click MCP connection can download **cloudflared 2026.10.0**, developed by Cloudflare, Inc., under the Apache License 2.0. cloudflared is optional and runs locally as a managed child process; the application downloads official release assets only after user consent and verifies pinned SHA-256 digests before installation.
